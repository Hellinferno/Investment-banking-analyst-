# Your SerpApi hackathon handoff

This folder is a build brief for Codex. It contains the plan and instructions, not a replacement copy of your application. The project already has a SerpApi integration on a feature branch. Codex should finish and prove that work, then add one focused analyst review feature if time permits.

Prepared: 8 October 2026. Recommended track: **Commerce & Market Intelligence**. A strong submission is the goal; no plan can guarantee an award.

## Do these steps

1. Extract this ZIP.
2. Open [OpenAI's getting-started guide](https://developers.openai.com/codex/quickstart/). In the desktop app, sign in, select Codex, and choose the project folder for software development. You can also use the supported IDE/CLI workflow.
3. Open a checkout of [your investment banking repository](https://github.com/Hellinferno/Investment-banking-analyst-). Start from the branch below, unless Codex confirms it has already been merged. If you have no checkout, give Codex the repository URL and ask it to clone that branch.
4. Copy the extracted `serpapi-codex-handoff` folder into the repository at `docs/codex-handoff/`. Open [01_CODEX_MASTER_PROMPT.md](01_CODEX_MASTER_PROMPT.md), copy the text between its prompt markers, and send it to Codex.
5. Let Codex implement and test the plan. When asked for a live key, put your SerpApi key in your local backend `.env` yourself. Do not paste it into chat, GitHub, screenshots, or a frontend variable.
